# Project Structure

## Root Configuration

- `.projenrc.ts` - Main projen configuration (source of truth for project setup)
- `package.json` - Generated by projen, do not edit manually
- `tsconfig.json` - TypeScript configuration for source code
- `tsconfig.dev.json` - TypeScript configuration for development
- `vitest.config.ts` - Vitest test configuration
- `biome.jsonc` - Biome linter/formatter configuration
- `mise.toml` - Node.js version specification

## Source Code

- `src/` - Source TypeScript files
  - `src/index.ts` - Main entry point, exports `AwsCdkApp` class
  - `src/AwsCdkAppOptions.generated.ts` - Generated options interface (created by jsii-struct-builder)

## Build Artifacts

- `lib/` - Compiled JavaScript and type definitions
- `dist/` - Distribution packages for jsii targets
- `.jsii` - jsii assembly metadata

## Tests

- `test/` - Test files using Vitest
  - `test/__snapshots__/` - Vitest snapshot files
  - Test files use `.test.ts` suffix

## Coverage

- `coverage/` - Test coverage reports (generated, not committed)

## Key Patterns

- **Generated Files**: Files with `.generated.ts` suffix are auto-generated and should not be manually edited
- **Projen Managed**: Most configuration files are generated by projen from `.projenrc.ts`
- **ES Modules**: All code uses ESM syntax (`import`/`export`, not `require`)
- **Class-based**: Main export is `AwsCdkApp` class extending projen's `AwsCdkTypeScriptApp`
- **Options Pattern**: Configuration uses TypeScript interfaces with optional properties
